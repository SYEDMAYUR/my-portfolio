# Mayur — Advanced Developer Portfolio

A responsive portfolio built with React, TypeScript, Vite, Tailwind CSS v4, Three.js / React Three Fiber, Drei, Framer Motion, and Lucide React.

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Personalize before publishing
1. Search the project for `Mayur` and update the copy as needed.
2. In `src/App.tsx`, replace `YOUR_EMAIL@example.com` with your real public contact email.
3. Replace the generic GitHub and LinkedIn links with your own profile URLs.
4. In `src/data/projects.ts`, replace each placeholder repository URL with the real project repository.
5. Only list skills you know or are actively learning, and update education details to your preference.
6. Put your resume PDF at `public/resume.pdf` if you want to add a resume download button.

## Deploy
Push the folder to GitHub, then import the repository into Vercel. Vite's build command is `npm run build` and output directory is `dist`.
